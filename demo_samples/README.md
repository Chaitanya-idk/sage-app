# Demo samples

Five images per disease (24 diseases across 5 crops, 120 images), for demonstrating SAGE.

- Taken evenly from the **test split** of [tejaanish/sage-india-crops](https://huggingface.co/datasets/tejaanish/sage-india-crops), so the models did not train on them.
- The folder name is the true label: `<crop>/<disease>/sample_N.jpg`. `manifest.csv` lists each image's original source.
- License: CC-BY-4.0. Subset of [tirtho149/SAGE](https://huggingface.co/datasets/tirtho149/SAGE) (Arshad et al., arXiv:2605.09768).
